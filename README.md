Final project for CS-492 Computer Security

Submission requirements
1. Commented Application source code
2. Word document that briefly describes your application and what class concepts/algorithms
   you incorporated and why you feel the design you choose was well suited to application
   functionality. You must include well thought out justification for your design decisions.
3. Recorded Video Presentation (6-10 mins total) – Submit a recording of you/your team that:
   1. (2-3 mins) Explains what your project is and how it incorporates class concepts
   2. (3-5 mins) Demonstrates your application
   3. (1-2 mins) Summarizes how professional ethics apply to the topic whether your
   project specifically or the topic generally
4. In class Final Project Peer Understanding Assessment – During final project presentations
   of others you will be required to identify concepts that apply to other projects as well as
   security and/or concept explanation flaws as they are presented, which makes up a component
   of your final project grade.
5. Contributes 17 percent toward the course total
